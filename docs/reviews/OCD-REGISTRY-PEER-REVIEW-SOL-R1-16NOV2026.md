## Sol review (verbatim)

VERDICT: FIX-FIRST

Several errors could misdirect the next builds. Reviewed 62 Python files; all 39 backing references resolve. The loader verifies file existence, not operational fit.

- **MEDIUM — `adcs` — existing enumeration marked `GAP`.** [`network/nxc_ldap.op_adcs()`](/srv/share/dev/purplesploit/python/purplesploit/modules/network/nxc_ldap.py:151) explicitly invokes ADCS enumeration. Correct mapping: **PARTIAL**, with NetExec credited for basic discovery. Keep full certificate assessment and ESC operations missing.

- **MEDIUM — `low_access` — wrong sole backing and a misleading WinPEAS gap.** [`recon/aranum`](/srv/share/dev/purplesploit/python/purplesploit/modules/recon/aranum.py:172) exposes remote service enumeration; this does not establish on-host privilege-escalation enumeration. Meanwhile, [`deploy/script`](/srv/share/dev/purplesploit/python/purplesploit/modules/deploy/script.py:178) already uploads and executes supplied WinPEAS artifacts. Correct mapping: retain **PARTIAL**, credit that conditional delivery/execution path, and separate artifact availability and execution prerequisites from the genuinely missing SEImpersonate/Potato operation. WinPEAS enumeration and SEImpersonate exploitation should not share one gap entry.

- **MEDIUM — `acl` — LAPS and gMSA retrieval disappear from the build ledger.** Neither NetExec adapter exposes dedicated retrieval handlers/options, while [the missing list](/srv/share/dev/purplesploit/python/purplesploit/capabilities/ocd_registry.json:429) omits both subjects. Correct mapping: retain **PARTIAL**; credit secretsdump/NXC NTDS for DCSync and LDAP for ACL collection, but explicitly add **LAPS-password retrieval** and **gMSA-password retrieval** wrappers as missing.

- **MEDIUM — `trusts` — generic MSSQL access credited toward SQL links.** [`network/nxc_mssql`](/srv/share/dev/purplesploit/python/purplesploit/modules/network/nxc_mssql.py:46) exposes authentication, database/table enumeration, privilege checks and command execution, without a linked-server enumeration/traversal operation. Correct mapping: qualify it as a prerequisite or remove it from operative backing; add **MSSQL linked-server enumeration/traversal** to missing capabilities. LDAP trust enumeration remains valid backing; **PARTIAL** remains appropriate.

- **MEDIUM — `know_vuln_auth` — GPP recovery is unaccounted for.** The listed GPP subject has no dedicated recovery/decryption implementation and no corresponding [missing entry](/srv/share/dev/purplesploit/python/purplesploit/capabilities/ocd_registry.json:281). Add **GPP cpassword discovery/recovery/decryption** as missing. Also, [`op_nopac()` and `op_printnightmare()`](/srv/share/dev/purplesploit/python/purplesploit/modules/network/nxc_smb.py:466) already wrap detection: **PARTIAL, detection only** is more accurate than `STUB`; exploitation PoCs remain missing.

These inventory additions are nonblocking refinements:

- **LOW — `no_creds` — omitted `recon/auto_enum`.** Its [orchestration](/srv/share/dev/purplesploit/python/purplesploit/modules/recon/auto_enum.py:712) backs network discovery and DNS/SMB enumeration. Add it without changing **PARTIAL**. The `smb/*` modules are [compatibility views](/srv/share/dev/purplesploit/python/purplesploit/modules/smb/_compat.py:6), so their omission does not hide additional implementations.

- **LOW — `low_hanging` — omitted existing checks and web operations.** Add `network/nxc_smb` for MS17-010/Zerologon checks, [`web/sqlmap`](/srv/share/dev/purplesploit/python/purplesploit/modules/web/sqlmap.py:166) for SQL-injection enumeration/extraction, and [`web/wpscan`](/srv/share/dev/purplesploit/python/purplesploit/modules/web/wpscan.py:380) for weak WordPress credentials. These do not close unrelated n-day exploitation gaps.

- **LOW — `authenticated` — collection gap needs qualification.** [BloodHound collection handlers already exist](/srv/share/dev/purplesploit/python/purplesploit/modules/network/nxc_ldap.py:168). Describe the remaining work as **CE compatibility/qualification or dedicated collector integration**, rather than collection from scratch. Static wrapper presence does not establish CE-compatible output.

- **LOW — `sccm` — generic backing is misleading.** `network/nxc_mssql` contains no SCCM-specific operation. Remove it from operative backing or explicitly label it a prerequisite; retain **GAP** and the deferred SCCM tooling requirement.

No inspected module warrants upgrading MITM listen/relay coverage, delegation abuse, or the named persistence primitives. Generic execution, payload deployment and broad collection do not establish those operations.
